Backups
and recovery.

Installation availability

Installation is not yet available in this version. You can back up your Kobo and prepare a Tailscale policy. The intended model is Kobo Libra Colour with firmware 4.46.23836. Other models and firmware versions are not supported.

Save your backups

Select the Kobo’s USB drive and a separate private backup folder on your computer. Keep the Kobo connected until copying and file checks finish. You’ll save a separate copy of its system settings during installation.

Backups may contain account details and device keys. Store them in a private location. Files and policies are processed on your computer and are not uploaded.

Resume an interrupted backup

If a backup stops before it finishes, keep the partial copy and create another backup. After refreshing, select the Kobo and the parent folder containing your backups. KoBOLD finds and checks existing manifests. Backups need an incremental update when their files no longer match the reader. Keep earlier backup folders: later backups may reuse unchanged files stored there.

If installation stops

Keep the Kobo connected. Do not eject or reboot it while an incomplete KoboRoot.tgz update is present. Check the error message before proceeding. If cleanup failed, inspect .kobo/KoboRoot.tgz and remove only the incomplete package from this installation.

A backup does not prevent damage from a power failure during installation. If the Kobo cannot start, factory recovery may be required and may erase its data.

Disable or remove startup

Open Recovery and choose Disable automatic startup or Remove automatic startup. Safely eject the Kobo and wait for it to finish, then restart it to stop Tailscale. Your books, settings and Tailscale registration will be kept.

After a firmware update, the startup files may need repair before these actions can run. Check the new firmware version before reinstalling.

Restore settings

Keep the original backup and later settings copies together. Compare the current settings with your saved copy and restore only the changes you need. Restoring an older library database can undo reading progress and annotations.

Back up your Tailscale policy

  1. Open the Tailscale JSON editor ↗ and sign in to the correct account.
  2. Before changing anything, select and copy the entire policy in the editor, including any comments.
  3. Paste it into a plain-text editor and save it on your computer as tailscale-policy-before-changes.hujson. Keep this file private.
  4. Reopen the saved file and check that the complete policy is present. Keep the backup until you have checked that your devices still connect after any changes.

To undo a policy change, paste the saved policy back into the Tailscale JSON editor, validate it and save. Use a device that still has access to the admin console.

Review Tailscale access

Allow the Kobo tag to reach only your Calibre-Web server and required TCP port. Existing rules may give it additional access. Review the full policy and validate it in Tailscale before saving. Deny entries are tests, not blocking rules.

The allowed port gives the reader access to Calibre-Web. Check that its Calibre-Web account has only the permissions it needs.

Save a bug report

Diagnostic events are recorded throughout setup, even when the log is hidden. Turn on Show diagnostic log in the header to read earlier events and current progress. Select a session, then choose Copy bug report or Download bug report.

Refreshing keeps the current session and its history. Reports exclude policy contents, credentials, sign-in links and book paths. If storage is unavailable or older events are removed, a warning appears. Export reports you want to retain; keeping them after the browser closes is not required.

Forget a setup session

To clear saved setup settings and folder references for this tab, open Forget this session. You can also add #forgetsession to the app’s address. Wait for any copying or installation operation to finish first.

This starts a separate setup session and returns to Overview. Diagnostic histories from earlier sessions in this tab are retained until you choose Clear diagnostic logs. It does not delete backup files, change the Kobo or revoke permissions already granted to this browser. If setup is open in another tab, use #forgetsession in that tab to clear its session.
