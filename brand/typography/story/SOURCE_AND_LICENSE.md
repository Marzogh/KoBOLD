# Source and licensing

KoBOLD Story Serif v1 is an adapted version of the open-licensed **Noto Serif Display** typeface by Google, under the **SIL Open Font License 1.1 (OFL)**. Source website: https://github.com/notofonts/latin-greek-cyrillic .

The new font family uses a different name from the upstream Noto family, modifies metrics and branding, and adds a small leaf ornament. The font builder preserves a full Unicode mapping from the source. The compiled font remains subject to OFL 1.1 and must not be relicensed as proprietary.

Before public distribution of the derivative, include the official OFL 1.1 text and verify the current upstream copyright and any reserved-font-name notices against the downloaded source package. The local system's Noto font copyright file identifies Google as copyright holder under SIL OFL 1.1.

This source package does not contain upstream Noto font binaries or locally compiled font files.
