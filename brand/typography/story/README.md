# KoBOLD Story Serif

A heading typeface adapted from Noto Serif Display. The supplied builder renames
the family, adjusts spacing and adds a three-leaf ornament. Original letter
outlines and Unicode coverage are retained. Use the Regular (400) and Medium
(500) weights for headings; use the system sans serif for controls and prose.

The upstream font is licensed under the SIL Open Font License 1.1. Preserve
../OFL-NotoSerifDisplay.txt and the upstream copyright metadata when distributing
this derivative. Source URLs, commit and hashes are pinned in ../upstream.json.
See ../README.md for the complete build procedure and dependency lockfile.
